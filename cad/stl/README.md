# 3D-Printable STL Files (GitHub Release)

The 27 `.STL` mesh files (~482 MB total) for the 18 logarithmic spiral joints, base plates, and auxiliary brackets are excluded from Git version control due to repository size limits and are distributed via **GitHub Releases**.

- **Source CAD**: Native SolidWorks parts/assemblies (`.SLDPRT` / `.SLDASM`) and neutral exchange formats (`.STEP` / `.DXF`) are tracked directly under [`cad/solidworks/`](../solidworks/) and [`cad/step_dxf/`](../step_dxf/).
- **STL Package**: Download the `cad-stl-*.zip` archive from the repository's **Releases** page and extract it into this directory if you want ready-to-slice meshes without exporting from SolidWorks.
